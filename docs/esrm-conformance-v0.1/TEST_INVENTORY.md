# ESRM v0.1 Test Inventory

This inventory maps every lexical-profile MUST/MUST NOT to at least one planned vector ID. Planned means the vector is specified for future Rust/Go implementation. Stopped means the vector family is blocked by an unresolved ESRM specification ambiguity and must not be implemented by local choice.

Machine-readable inventory: `manifests/esrm-test-inventory.v0.1.json`.
Binary vector manifest: `manifests/esrm-binary-vector-manifest.v0.1.json`.

No conformance claim is made.
