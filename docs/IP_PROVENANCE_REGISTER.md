## Rights inventory — pending independent review

Do not infer legal ownership from repository names, commit authors, signoffs,
GitHub permissions, or a project's promotional name. Record **private**
supporting documentation outside this public repository for each material
copyrightable contribution:

1. Original human author(s) and dates, including prior local work.
2. Whether created personally, in employment or as commissioned work.
3. Employer/client ownership provisions or permissions, if applicable.
4. Any written license, work-for-hire agreement or assignment, with chain of
   title and effective date. **Never publish a signed agreement here.**
5. Third-party imports, copied snippets, external assets, licenses and
   retention of notices.
6. AI-assisted portions and any substantial human creative contributions.
7. Whether an agreed company actually holds title; record a signed transfer
   separately if one is executed.
8. Repository history reference: commit, PR, artifact hash and review evidence.

## Trademark and naming

The software license does not grant exclusive rights to the project name.
Product/company names and trademark clearance are independent of copyright
provenance. No trademark ownership, registration or exclusivity is asserted
by this document. Obtain a current trademark clearance assessment **before**
making brand claims, incorporating under a similar name or investing in
brand-specific domains and marketing.

## Technical evidence retention

- Preserve the original Git commit DAG and release tags; do not rewrite
  published history to manufacture a different priority date or author.
- Keep a verifiable, access-controlled backup separate from the GitHub account.
- For a historical claim, cite exact immutable commit SHA, upstream source,
  authored evidence and corresponding private legal instrument as appropriate.
- A Git tag, code hash or public commit establishes a record of bytes or
  metadata at a time; it does not itself establish authorship, trade secrecy,
  novelty, patent priority or assignment.
- Keep secrets, ownership contracts, government IDs and nonpublic counsel
  advice **out of this public repository and its Issues/Actions logs**.

## Completion gate

Before selling or assigning rights to a customer, investor or new company,
have qualified counsel review actual chain-of-title evidence and the existing
Apache-2.0 obligations. Do not tell buyers that a company owns all source
code, or that the name is exclusively protected, without verified grounds.
